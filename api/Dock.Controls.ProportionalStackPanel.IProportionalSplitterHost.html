Allows a panel with its own sizing policy to use Dock's splitter input and preview.

public interface IProportionalSplitterHost

Remarks

Implement this interface on the panel containing the panes and splitters. Splitters can be direct children or the content of a child content presenter. Collapsed panes are identified by IsCollapsedProperty.

Remarks

The host applies its own constraints and persists the resulting dimensions. Preview gestures invoke this method only on release; live gestures invoke it on movement.
