Optional factory policy for validating docking destinations.

public interface IDockDropPolicy

Remarks

DockManager checks participating factories before showing targets or executing a drop. Implementations must not mutate the layout. Factories without this policy retain native behavior; direct factory collection operations do not consult the policy.
