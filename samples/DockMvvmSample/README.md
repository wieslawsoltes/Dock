# DockMvvmSample

This sample demonstrates the full Dock MVVM layout, view-location, docking,
floating-window, serialization, global-tracking, theme-variant, and preset flows.
It uses Avalonia Fluent and `DockFluentTheme` by default.

To run it:

```bash
dotnet run --project samples/DockMvvmSample/DockMvvmSample.csproj
```

To convert the same sample to Avalonia Simple and `DockSimpleTheme`, follow the
[build-verified Simple theme conversion guide](../../docfx/articles/dock-theme-simple.md#switch-dockmvvmsample-from-fluent-to-simple).
